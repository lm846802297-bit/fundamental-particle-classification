# Contributing

Contributions should improve the source-based classification or make its reasoning easier to audit.

## Research claims

- Cite primary sources for theorem statements and constructions. Include DOI, arXiv ID, or another stable identifier when available.
- Record definitions and hypotheses alongside conclusions, especially dimension, locality, localization, and particle criteria.
- Separate proved results, model-dependent claims, interpretation, and conjecture.
- Compare a proposed gap against nearby literature before describing it as novel.

## Changes and review

- Work on a descriptive branch and open a pull request for substantive changes.
- Explain what changed, why it is correct, and which sources support it.
- For calculations, include source version, input hashes, environment and parameters, native outputs, convergence/error analysis, and an independent physical check.
- Keep follow-up questions distinct from acceptance criteria for the current result.
